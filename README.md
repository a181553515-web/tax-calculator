# 2026 个税与社保公积金计算器

小波财税日记提供的免费财税测算工具，采用纯静态网页实现，无需安装或登录。

## 在线工具

| 工具 | 地址 | 主要功能 |
| --- | --- | --- |
| 个人所得税计算器 | <https://xiaobo-tax.cn/> | 工资薪金、年终奖、汇算清缴、经营所得及其他常见个人所得 |
| 社保公积金计算器 | <https://xiaobo-tax.cn/social-insurance.html> | 五险一金用工成本、公积金缴存、公积金贷款额度与月供 |

## 功能概览

### 个人所得税

- 工资薪金单月计算、累计估算和累计精算
- 年终奖计税方式对比
- 综合所得汇算清缴
- 经营所得、劳务报酬、稿酬、特许权使用费等常见场景
- 保险营销员、证券经纪人、律师、非居民个人及股权激励等特殊口径

### 社保公积金

- 输入税前工资测算个人缴费、员工实收和企业用工成本
- 按员工目标工资或企业预算反算税前工资
- 支持工资与社保缴费基数分离、按当地下限测算
- 公积金缴存额与实缴基数反推
- 公积金贷款额度、月供及轻量商贷对比

## 政策数据维护

- 安徽合肥、六安使用实测口径，其他地区区分官方核验数据与常见参考口径。
- 社保和公积金缴存上下限统一维护在 `social-policy-data.js`。
- 公积金贷款利率和城市额度政策维护在 `housing-fund-policy-data.js`。
- 政策来源和复核记录保存在 `docs/policy-sources/`，计算结果仅供测算参考，不作为申报或结算依据。

## 本地运行与测试

直接用浏览器打开 `index.html` 或 `social-insurance.html` 即可使用。

```bash
node --test tests/*.test.js
```
