# 轻量商贷对比

用户确认：默认关闭的商贷对比，共用金额、年限和还款方式，仅增加商贷利率输入。参考文字分首套、二套，不作为全国报价或默认利率。

数据：近期多地首套5年以上约3.0%—3.1%，报道实地咨询广州、杭州的二套亦与首套同价。提示限定“近期多地”，不代表所有城市；不计贴息、特殊优惠。复核日期2026-09-16。

来源：https://finance.sina.com.cn/money/bank/bank_hydt/2026-08-07/doc-inimnvkm3146388.shtml

复用现有还款计算引擎。展示双方月供（等额本金为首月）、总利息差额，差额方向允许反转。自定义当前利率时不将其标为公积金政策利率。商贷输入无效只取消对比，不阻断原计算。全程利率不变假设，不增加商贷还款明细。

修改范围仅贷款月供入口、商贷参考提示配置、相关测试。社保与缴存数据不变，仅本地审核，不发布。
