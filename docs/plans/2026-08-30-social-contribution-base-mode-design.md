# 社保缴费基数轻量设置设计

## 目标

解决税前工资与社保缴费基数始终绑定的问题，使三个测算模块都能表达“工资 5000 元、社保按当地缴费下限计算”等常见用工成本场景，同时保持当前页面简洁。

## 交互范围

三个测算模块共用一组“社保缴费基数”选项：按工资、按最低基数、自定义。默认仍为“按工资”，维持现有结果；选择“按最低基数”后，计算器自动采用当前参保地区各险种自己的缴费下限；只有选择“自定义”时才展开一个金额输入框。

税前工资输入框恢复普通工资示例，不再提示用户把最低基数填写为工资。参保地区变化时，下方用一行小字展示当前采用的基数口径。住房公积金本版继续按工资及当地公积金上下限计算，不增加第二套基数控件，避免输入区过重。

## 计算规则

- 按工资：各险种以税前工资为起点，再分别套用当地上下限。
- 按最低基数：养老、医疗、失业、工伤分别采用各自下限，不假设所有险种下限相同。
- 自定义：用户输入一个社保基数，各险种再分别套用当地上下限；超出范围时在结果中显示实际采用值。
- 反算工资和按预算算工资：先固定当前基数方式，再反算税前工资，避免基数随反算结果错误变化。

## 验证

自动测试覆盖原有按工资结果不变、安徽工资与最低基数分离、深圳医保独立下限、自定义基数上下限及两种反算模式。移动端检查三档控件不拥挤、自定义输入按需展开、地区切换后提示同步更新，并确认页面无横向溢出。
