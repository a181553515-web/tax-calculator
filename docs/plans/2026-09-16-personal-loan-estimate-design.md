# 个人公积金贷款额度测算（本地评审）

用户已确认：金额输入阻断并允许主动换算；两处公积金共用政策解析和计算；将政策上限整合进“算算我能贷多少”。

## 范围

- 万元框严格识别数字，实时展示元金额；超过1000万元触发输入防错，不把阈值称为政策上限，不自动更改金额。
- 共用缴存基数解析与缴存计算，保留原有安徽实测值及两位小数结果。
- 个人额度先支持合肥（新建商品住房）、六安（单位职工购房）；其他城市只查政策上限。
- 合肥：基数×0.6×12×年限、分人余额×时间倍数、政策上限、房价减首付取低值；余额不足3万元按3万元，6—24个月15倍，超过24个月20倍。
- 六安：月缴存额（双边合计）×12×20，18万元公式保底；还款能力、购房差额、政策上限取低值。二手房额外校验房龄。
- 只做参考金额测算，不声称审核征信、套数、退休年龄、担保、资金提取或特殊优惠资格；实际可贷年限由用户结合当地条件确认。
- 规则与来源集中在贷款政策文件；不完整的公式不得开放个人测算。

## 验证

测试金额单位误填、非法字符、期限、两处缴存一致、个人/夫妻、低余额保底、政策上限、房价、还款能力、二手房龄、缺参数及不支持城市。浏览器复现前后对照，手机375px检查溢出。仅本地提交，不部署。
# 本轮审核后的简化调整

用户确认入口改为“算贷款额度”。不输入购房总价及首付，不把购房价款作为本模块的计算约束。结果是缴存条件测算上限，不是实际获批额度；实际仍受房价、首付、还款能力及审批条件限制。

六安家庭收入、其他贷款、利率档次及还款方式统一折叠为可选“还款能力校验”，须主动勾选才参与计算。合肥不展示该区。以下原设计中涉及购房价款和必填收入的内容由本节取代。
